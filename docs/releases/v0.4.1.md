## 0. About this release

v0.4.1 is the first public release of Fincas, published under the MIT license
at `github.com/Logos-Flux/fincas` and on PyPI as `fincas`. It is v0.4.0 plus
the release preparation: no schema changes, no new required secrets.

The public repository starts from one squashed commit per release; the
development history is not published. Issue numbers in section 5 refer to that
private history.

Install with `pip install fincas==0.4.1`; the import name stays `golden_erp`.
New here: start with [docs/getting-started.md](../getting-started.md).

## 1. Before you upgrade

Upgrading from v0.4.0:

1. Rename `GOLDEN_PLUGINS` / `GOLDEN_PLUGIN_APPS` entries that start with
   `addons.` to `golden_erp.addons.`. The old spelling still loads the same
   plugin, with a `DeprecationWarning`, until 0.6.0. Listing both spellings of
   one plugin is refused.
2. If your deployment points the ERP assistant at its own API, set
   `GOLDEN_ERP_API_KEY` and `GOLDEN_ERP_BASE`. Older deployment-specific
   variable names are no longer read.
3. If you run several companies' records in one database and relied on the
   order and quote editors preselecting one, set `GOLDEN_DEFAULT_COMPANY_NAME`.
4. `manage.py migrate` applies nothing (no new migrations) and
   `manage.py makemigrations --check` reports no changes.

## 2. Behavior changes staff will notice

- Document emails (order confirmation, shipping notification, invoice,
  quote) are headed with the configured company name
  (`ERP_BRAND["company_name"]`). Before, the order and shipping emails showed
  the fallback "Commerce", and invoice and quote emails a fixed name.
- The invoice's order reference reads "Sales Order #".
- A storefront visitor whose stored theme was the renamed `solar-industrial`
  skin's old id sees the default theme until they pick one again.

## 3. Known limitations

Everything in [v0.4.0 section 3](v0.4.0.md#3-known-limitations) still holds,
including: one company per instance (`core.E070`), and the CRM importer's
advisory lock, which must reach Postgres directly rather than through a
transaction-mode pooler (`docs/deployment.md`).
