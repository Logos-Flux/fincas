## 0. About this release

v0.4.3 is a maintenance release for the release harness only: nothing in the
installed package changes behavior. It makes the nightly journeys pass on
GitHub-hosted runners, where they failed in this repository since v0.4.2:

- **R2.08 and R5.04**: the harness clicked the next sidebar link before the
  previous one's page had loaded, took the missing link for a narrow screen,
  and timed out on the hidden menu button. It now waits for each page.
- **R7**: the journey looked for the HubSpot fixture export at the
  pre-0.4.0 `addons/` path; it now reads it from `golden_erp/addons/`.

No migrations, no new settings and no new required secrets. Install with
`pip install fincas==0.4.3`; the import name stays `golden_erp`.

## 1. Before you upgrade

Upgrading from v0.4.2: install the new version. `manage.py migrate` applies
nothing. From v0.4.1, follow the v0.4.2 notes first
([docs/releases/v0.4.2.md](v0.4.2.md) section 1).
